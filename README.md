# BriefJob

현대/기아 1차 협력사와 자동차 부품 산업 뉴스를 수집하고, 취업 준비용 기업 브리핑을 보여주는 Flask 기반 웹 앱입니다.

## 주요 기능

- 네이버 뉴스 검색 API와 카카오 웹 검색 API 기반 최신 뉴스 수집
- 검색창 아래 `추천 키워드`와 좌측 `추천 기업` 분리
- 추천 기업 클릭 시 해당 기업 뉴스 즉시 수집 및 결과 표시
- 뉴스 목록 페이지네이션: 한 페이지당 50개 표시
- 카테고리 필터, 기사 내 검색, 브리핑 상태 유지 페이지 이동
- LLM API 설정 시 뉴스 요약, 기업 리서치, 예상 면접 질문, 답변 준비 방향 생성
- 고용24 API 설정 시 현재 채용공고 표시
- 사람인/잡코리아 등 공개 회사정보 페이지에서 복리후생·근무제도 요약 표시
- 사람인 면접후기 공개 페이지에서 면접 유형, 난이도, 질문, 전형 진행 방식 요약 표시
- 수집 결과는 `data/news.json`, LLM 응답 캐시는 `data/llm_cache.json`에 저장

## 추천 키워드와 추천 기업

검색창 아래 추천 키워드는 산업/직무 중심입니다.

```text
자동차 부품, 전장 부품, 전기차, 공급망
```

좌측 추천 기업에는 다음 기업이 들어 있습니다.

```text
영진정공, 네오오토, 동보, 지엠비코리아, 현대성우캐스팅, 현대케피코, 현대파워텍,
경창산업, 남양공업, 대승, 인팩, 리한, 코리아에프티, 현대성우메탈, 센트랄,
현대위아, 에스엘, 금강화학, 대원산업, 동아화성, 서연이화, 아성프라텍,
아진산업, 삼송, 두올, 두올산업, 세동, LS오토모티브, 서연전자,
유라코퍼레이션, 인팩일렉스, 만도, THN, 티에이치엔, 현대성우쏠라이트,
동원금속, 베바스토동희, 성우하이텍, 세원정공, 금창, 경신, 두원공조,
세명테크, 위너콤, 트래닛, 평화산업
```

`THN`은 `티에이치엔`과 같은 회사로 검색되도록 alias 처리되어 있습니다.

## 브리핑 데이터 정책

### 뉴스

- 네이버 뉴스 API와 카카오 웹 검색 API를 사용합니다.
- 추천 기업 검색은 먼저 회사명으로 검색합니다.
- 결과가 부족할 때만 `회사명 자동차부품`, `회사명 현대차`, `회사명 채용` 조합을 추가로 검색합니다.
- API 호출이 과도해지지 않도록 보강 검색은 제한되어 있습니다.

### 복리후생·근무제도

- 사람인, 잡코리아, 인크루트, 원티드, 캐치, 워크24 등 공개 회사정보/기업정보 페이지를 사용합니다.
- 채용공고 페이지는 복리후생 근거에서 제외합니다.
- 같은 도메인의 회사정보가 여러 번 잡히면 요약이 더 풍부한 1개만 화면에 표시합니다.
- 화면에는 전체 페이지 원문이 아니라 복리후생 관련 짧은 요약만 표시합니다.

### 면접후기

- 사람인 면접후기 공개 페이지가 검색되면 `interview_review` 자료로 분리합니다.
- 면접후기는 복리후생이나 회사 공식 정보 근거로 사용하지 않습니다.
- 전형 방식, 면접 유형, 난이도, 질문, 준비 포인트에만 참고합니다.
- 후기 내용은 회사 공식 사실처럼 단정하지 않고 후기 기준 자료로만 취급합니다.

### 고용24 채용 현황

- `WORK24_API_KEY` 또는 `WORK24_JOBS_API_KEY`가 있으면 기업 브리핑에서 현재 채용공고를 표시합니다.
- 표시 항목은 공고 제목, 회사명, 지역, 마감일, 급여, 고용24 공고 링크입니다.
- `THN` 검색 시 고용24 조회는 `티에이치엔`으로 보정합니다.

### LLM 답변 정책

- 블라인드/커뮤니티/비공개 후기를 본 것처럼 말하지 않도록 프롬프트에 제한을 둡니다.
- 복리후생과 근무환경은 회사정보 공개 페이지 기준으로 확인된 내용만 사용합니다.
- 지원자가 해당 회사 복리후생이나 근무환경을 직접 경험한 것처럼 쓰는 문장은 금지합니다.
- `복리후생/근무환경에 대한 긍정적인 경험 공유` 같은 부자연스러운 답변 준비 문구는 후처리에서 제거합니다.

## 프로젝트 구조

```text
.
├── app.py                 # Flask 앱과 화면 라우팅
├── config.py              # 환경변수, 기본 키워드, 추천 기업 목록
├── news_collector.py      # 네이버/카카오 뉴스 수집 및 필터링
├── company_research.py    # 공개 회사정보·면접후기 검색 및 요약 추출
├── work24_client.py       # 고용24 채용정보 API 클라이언트
├── llm.py                 # LLM 브리핑 생성 및 캐시
├── requirements.txt       # Python 의존성
├── .env.example           # 환경변수 예시
├── data/
│   ├── news.json          # 수집 뉴스 저장 파일
│   └── llm_cache.json     # LLM 응답 캐시
├── templates/
│   └── index.html         # 메인 화면
└── static/
    └── style.css          # 화면 스타일
```

## 실행 방법

### 1. 가상환경 만들기

Windows PowerShell 기준:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

PowerShell 실행 정책 오류가 나면 현재 터미널에서만 다음 명령을 먼저 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 2. 패키지 설치

```powershell
pip install -r requirements.txt
```

### 3. 환경변수 설정

`.env.example`을 참고해 프로젝트 루트에 `.env` 파일을 만듭니다.

```env
NAVER_CLIENT_ID=your_naver_client_id
NAVER_CLIENT_SECRET=your_naver_client_secret
KAKAO_REST_API_KEY=your_kakao_rest_api_key
WORK24_API_KEY=your_work24_api_key

# 선택: 서비스별 고용24 키를 따로 쓰고 싶을 때
WORK24_JOBS_API_KEY=your_work24_jobs_api_key
WORK24_SMALL_GIANTS_API_KEY=your_work24_small_giants_api_key
WORK24_JOB_DUTY_API_KEY=your_work24_job_duty_api_key

# 선택: AI 브리핑 사용 시
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4o-mini
```

네이버와 카카오 키 중 하나만 있어도 뉴스 수집은 동작합니다. `KAKAO_REST_API_KEY`가 있으면 공개 회사정보/면접후기 검색 보강이 가능하고, `WORK24_API_KEY`가 있으면 현재 채용공고를 표시합니다. `OPENAI_API_KEY`가 없으면 AI 브리핑은 fallback 방식으로 동작합니다.

### 4. 뉴스 수집 실행

기본 산업 키워드로 수집:

```powershell
python news_collector.py
```

특정 기업 또는 키워드로 수집:

```powershell
python news_collector.py --keywords 영진정공 현대위아 전기차
```

수집 결과는 `data/news.json`에 저장됩니다.

### 5. 웹 앱 실행

```powershell
python app.py
```

브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:5000
```

## 사용 흐름

1. 검색창에 회사명이나 산업 키워드를 입력하고 `검색`을 누릅니다.
2. 좌측 `추천 기업`에서 기업명을 클릭하면 해당 기업 뉴스가 바로 수집되고 결과가 표시됩니다.
3. 뉴스가 표시된 상태에서 `뉴스 요약`을 누르면 기업 브리핑을 볼 수 있습니다.
4. 기업 브리핑에서 고용24 채용 현황, 공개 회사정보 복리후생, 사람인 면접후기 요약, 기업 개요, 최근 이슈, 예상 면접 질문을 확인합니다.
5. 브리핑 상태에서 다음/이전 페이지로 이동해도 브리핑 화면이 유지됩니다.

## 참고

- API 검색 결과 자체가 적은 기업은 결과 수가 적을 수 있습니다.
- 사람인/잡코리아 등 공개 페이지는 필요한 요약만 추출하며 전체 원문을 저장하거나 화면에 그대로 복제하지 않습니다.
- 채용공고 페이지는 현재 채용 현황에는 사용할 수 있지만, 복리후생 근거로는 사용하지 않습니다.
- `data/news.json`과 `data/llm_cache.json`은 실행 중 갱신되는 데이터 파일입니다.
